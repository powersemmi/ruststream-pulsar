# Топики

Топик Pulsar находится в пространстве имён, которое принадлежит арендатору (tenant).
Персистентный топик хранит свои сообщения в BookKeeper, а партиционированный топик - это по
одному топику на партицию.

<Diagram name="topics" words={words} />

Полное имя топика - `{persistent|non-persistent}://tenant/namespace/topic`. Арендаторы и
пространства имён - единицы администрирования Pulsar: права доступа, политика хранения и другие
политики задаются на них. [`PulsarTopic`](api:ruststream_pulsar::PulsarTopic) разбирает имя до
любого ввода-вывода, а короткое имя, например `orders`, превращается в
`persistent://public/default/orders`.

Персистентный топик записывает каждое сообщение в леджеры (ledgers) BookKeeper. Сообщение
хранится там, пока его не подтвердит каждая подписка, а затем столько, сколько требует политика
хранения пространства имён. Неперсистентный топик ничего не хранит: сообщение уходит консьюмерам,
подключённым в этот момент, и консьюмер, который подключится позже, его не увидит.

Партиционированный топик - это набор внутренних топиков с именами `<topic>-partition-<n>`. Каждый
из них - отдельный журнал, и каждым владеет один брокер кластера. Партицию для каждого сообщения
выбирает продюсер. Продюсеры этого крейта выбирают партицию по хешу ключа сообщения, поэтому
сообщения одного ключа сохраняют порядок, а сообщения без ключа распределяют по партициям по
кругу. Доставка из партиционированного топика сообщает партицию в
[имени топика](api:ruststream_pulsar::PulsarMessage::topic).

Сервер создаёт персистентный топик, когда продюсер или консьюмер впервые его называет, если
автоматическое создание в кластере не выключено. Партиционированный топик вместе с числом
партиций создаёт администратор.

Эта модель взята у самого Apache Pulsar
([топики](https://pulsar.apache.org/docs/next/concepts-messaging/#topics),
[мультиарендность](https://pulsar.apache.org/docs/next/concepts-multi-tenancy/),
[партиционированные топики](https://pulsar.apache.org/docs/next/concepts-messaging/#partitioned-topics),
[неперсистентные топики](https://pulsar.apache.org/docs/next/concepts-messaging/#non-persistent-topics)).
Как консьюмеры читают топик, показывает страница [Подписки](subscriptions.md).
